# saad-sana-waleema-invitation

Dawat-e-Walima invite for Md. Saad & Sana: Monday, 9 November 2026, after Namaz-e-Maghrib, Abuji Marriage Ground, Bhiwandi.

- `index.html` is the invite. Add `?to=Guest-Name` to the link to greet a guest by name.
- `send.html` is the private page for sending each guest their link on WhatsApp.
- If the site address changes, update `og:url` and `og:image` in `index.html` and the default address in `send.html`.
